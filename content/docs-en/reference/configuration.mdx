# Configuration Reference

GoClaw reads configuration from a JSON5 file. Secrets are kept separate from `config.json` and loaded only from environment variables or a `.env.local` file.

---

## Overview

- **Format:** JSON5 (supports `//` comments, trailing commas, unquoted keys)
- **Default location:** `~/.goclaw/data/config.json` (Desktop) or `./config.json` (Standard)
- **Override path:** Set `GOCLAW_CONFIG` to specify an explicit path
- **Security principle:** Secrets (API keys, tokens, DSN) must NEVER be stored in `config.json`

**Basic example:**
```json5
{
  // Gateway server settings
  gateway: {
    host: "0.0.0.0",
    port: 8080,
    token: "", // Leave empty, use GOCLAW_GATEWAY_TOKEN env var
  },
  agents: {
    defaults: {
      provider: "anthropic",
      model: "claude-sonnet-4-5",
      max_tokens: 8192,
    }
  }
}
```

## Section: gateway

Controls the gateway server.

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `host` | string | `"0.0.0.0"` | Listen address |
| `port` | int | `8080` | Listen port (Desktop: 18790) |
| `token` | string | `""` | Bearer token for WS/HTTP auth (secret — use env var) |
| `owner_ids` | []string | `[]` | Sender IDs treated as "owner" |
| `allowed_origins` | []string | `[]` | WebSocket CORS whitelist (empty = allow all) |
| `max_message_chars` | int | `32000` | Maximum characters per user message |
| `rate_limit_rpm` | int | `20` | Request rate limit per user per minute (0 = off) |
| `injection_action` | string | `"warn"` | Action on prompt injection detection: `log`, `warn`, `block`, `off` |
| `inbound_debounce_ms` | int | `1000` | Merge rapid messages from same sender (ms, -1 = off) |
| `block_reply` | *bool | `false` | Send intermediate text while tools are running |
| `tool_status` | *bool | `true` | Show tool name in streaming preview |
| `task_recovery_interval_sec` | int | `300` | Interval for team task recovery check (seconds) |

### gateway.quota

Configure request quotas per user or group.

| Field | Type | Description |
|-------|------|-------------|
| `enabled` | bool | Enable/disable quota system |
| `default` | QuotaWindow | Default limit for all users |
| `providers` | map[string]QuotaWindow | Override by provider (key = provider name) |
| `channels` | map[string]QuotaWindow | Override by channel (key = channel name) |
| `groups` | map[string]QuotaWindow | Override by group (key = userID) |

**QuotaWindow:**
```json5
{
  hour: 20,   // max requests/hour (0 = unlimited)
  day: 100,   // max requests/day
  week: 500   // max requests/week
}
```

Merge priority: Groups > Channels > Providers > Default.

## Section: tools

| Field | Type | Description |
|-------|------|-------------|
| `profile` | string | `"minimal"`, `"coding"`, `"messaging"`, `"full"` |
| `allow` | []string | Allowlist (tool name or `"group:xxx"`) |
| `deny` | []string | Blocklist |
| `alsoAllow` | []string | Add to allowlist without removing existing |
| `rate_limit_per_hour` | int | Max tool executions/hour/session (0 = off) |
| `scrub_credentials` | *bool | Auto-redact API keys/tokens from tool output (default true) |

### tools.execApproval

| Field | Default | Description |
|-------|---------|-------------|
| `security` | `"full"` | `"deny"`, `"allowlist"`, `"full"` |
| `ask` | `"off"` | `"off"`, `"on-miss"`, `"always"` |
| `allowlist` | `[]` | Glob patterns for permitted commands |

### tools.web_fetch

| Field | Default | Description |
|-------|---------|-------------|
| `policy` | `"allow_all"` | `"allow_all"` or `"allowlist"` |
| `allowed_domains` | `[]` | Example: `["github.com", "*.example.com"]` |
| `blocked_domains` | `[]` | Always checked regardless of policy |

### tools.browser

| Field | Default | Description |
|-------|---------|-------------|
| `enabled` | `false` | Enable browser automation tool |
| `headless` | `false` | Run Chrome headless |
| `remote_url` | `""` | CDP endpoint for remote Chrome |
| `action_timeout_ms` | `30000` | Timeout per action (ms) |
| `idle_timeout_ms` | `600000` | Auto-close page when idle (ms, 0 = off) |
| `max_pages` | `5` | Max open pages per tenant |

### tools.mcp_servers

```json5
{
  tools: {
    mcp_servers: {
      "my-server": {
        transport: "stdio",        // "stdio", "sse", "streamable-http"
        command: "npx",
        args: ["-y", "@my/mcp-server"],
        env: {"API_KEY": "xxx"},
        tool_prefix: "my_",
        timeout_sec: 60,
        enabled: true
      }
    }
  }
}
```

## Section: sessions

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `scope` | string | `"per-sender"` | `"per-sender"` or `"global"` |
| `dm_scope` | string | `"per-channel-peer"` | DM session scope |
| `main_key` | string | `"main"` | Key suffix for the main session |

**`dm_scope` values:**

| Value | Description |
|-------|-------------|
| `"main"` | All DMs share a single session |
| `"per-peer"` | Each peer has its own session (shared across channels) |
| `"per-channel-peer"` | Each (channel, peer) pair has its own session (default) |
| `"per-account-channel-peer"` | Also includes bot account in the key |

## Environment Variables

| Variable | Description |
|----------|-------------|
| `GOCLAW_CONFIG` | Explicit path to config.json |
| `GOCLAW_GATEWAY_TOKEN` | Gateway bearer token |
| `GOCLAW_POSTGRES_DSN` | PostgreSQL connection string |
| `GOCLAW_REDIS_DSN` | Redis connection string (optional) |
| `GOCLAW_STORAGE_BACKEND` | `"postgres"` or `"sqlite"` |
| `GOCLAW_SQLITE_PATH` | SQLite DB path |
| `GOCLAW_PORT` | Override gateway port (Desktop) |
| `GOCLAW_TSNET_AUTH_KEY` | Tailscale auth key |

`.env.local` is automatically loaded if it exists alongside `config.json`. Environment variables take precedence over `config.json`.

**Example `.env.local`:**
```bash
GOCLAW_GATEWAY_TOKEN=my-secret-token
GOCLAW_POSTGRES_DSN=postgres://user:pass@localhost:5432/goclaw
ANTHROPIC_API_KEY=sk-ant-...
OPENAI_API_KEY=sk-...
```
