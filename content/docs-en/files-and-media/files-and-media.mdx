# Files & Media

## 1. Uploading Files in Chat

Two ways to send files to an agent:

- **Drag and drop** — drag a file into the chat window
- **Click to upload** — click the attachment icon (clip) in the input bar

The file is attached to the message; the agent receives and processes it alongside the text content.

---

## 2. Supported Formats

| Type | Formats |
|------|---------|
| Images | JPEG, PNG, GIF, WebP, BMP, TIFF |
| Video | MP4, AVI, MOV, MKV, WebM |
| Audio | MP3, WAV, OGG, FLAC, AAC, M4A |
| Documents | PDF, DOCX, XLSX, PPTX |
| Text / Code | TXT, MD, JSON, CSV, and other text files |

---

## 3. Document Processing

When the agent receives a document (PDF, DOCX, etc.), it uses the `read_document` tool to read and analyze content:

- **PDF** — extracts text from each page
- **DOCX** — reads Word document content
- **XLSX / PPTX** — reads spreadsheet data / slides

The agent can:
- Summarize the content
- Answer questions based on the document
- Extract specific information

> Note: `read_file` cannot read binary files. The agent automatically selects the correct tool based on the file format.

---

## 4. Image Analysis

Agents can describe and analyze images through the LLM's **vision** capability:

- Detailed description of image content
- Text recognition in images (OCR)
- Analysis of charts and diagrams
- Comparison of multiple images

Just send an image in the chat and ask a question — the agent analyzes it directly.

---

## 5. Audio & Voice

### Voice Messages (STT)

When you send a voice message via Telegram or Discord, the system automatically:
1. Receives the audio file
2. Runs Speech-to-Text (STT)
3. Converts the result to text
4. The agent processes the text like a regular message

### Audio File Upload

Upload audio files directly (.mp3, .wav, etc.) — the agent can extract content via the `read_audio` tool.

---

## 6. Image Generation

Agents can generate images from text descriptions using the `create_image` tool.

**Supported providers** (in priority order):
1. OpenRouter (Gemini 2.5 Flash Image)
2. Gemini
3. OpenAI (DALL-E 3)
4. MiniMax
5. DashScope (Wan 2.6)

**Example prompt:**

> "Generate an image of a cat sitting on a keyboard, anime style, blue background"

The agent calls `create_image` with the prompt, returns the file path. The file is saved to the workspace and sent to the user.

---

## 7. Text-to-Speech (TTS)

Agents convert text to speech using the `tts` tool.

**Supported providers:**

| Provider | Notes |
|----------|-------|
| OpenAI | Multiple voices, high quality |
| ElevenLabs | Natural voices, supports voice cloning |
| Edge TTS | Microsoft Edge, free |
| MiniMax | Supports Vietnamese |

**Example prompt:**

> "Read this paragraph aloud in a female voice"

The agent calls `tts` with the text and voice/provider options, returns an audio file (.mp3). The file is sent to the user.

---

## 8. Video Generation

Agents can create short videos from text or images using the `create_video` tool.

**Supported providers:**
- MiniMax Video

**Example prompt:**

> "Create a 5-second video: a beach at sunset, waves rolling in"

The agent returns the video file path after generation.

---

## 9. File Storage

Files generated by agents (images, audio, video) are saved to the **workspace**:

- **Standard edition** — stored in `data/` on the server, isolated per tenant
- **Lite edition** — stored in `~/.goclaw/workspace/`

### Accessing Files

Files are accessible via the HTTP API:

```
GET /v1/files/{path}?ft={token}
```

The token is short-lived, ensuring only authorized users can access the file.

### Limits

| Limit | Value |
|-------|-------|
| Max file size | 10 MB |
| Max files per workspace | 100 files |

### Files in Team Workspace

When an agent creates a file while executing a task, the file is:
- Automatically saved to the team workspace `attachments/` directory
- Linked to the task being executed
- Displayed on the task detail page in the Web UI
