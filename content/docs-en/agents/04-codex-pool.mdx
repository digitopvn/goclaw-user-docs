# Codex Pool

## Overview

Codex Pool is a feature for managing the ChatGPT OAuth routing pool for a specific agent. Instead of using a single ChatGPT OAuth provider, Codex Pool allows configuring multiple providers and routing requests by strategy (round-robin, primary-first, etc.) to increase availability and reduce the risk of hitting rate limits.

Route: `/agents/:id/codex-pool`
Sidebar Group: Core (sub-page of Agent)
Access: Admin

---

## What Is Codex Pool

ChatGPT OAuth is an authentication method to access ChatGPT via an OAuth flow instead of a regular API key. When an agent uses ChatGPT OAuth:

- Multiple ChatGPT OAuth accounts / providers can be configured.
- Codex Pool distributes requests to providers by strategy.
- If a provider encounters an error or hits a rate limit, the pool automatically switches to another provider (fallback).
- The system monitors the health of each provider in the pool in real time.

## Interface

The page has two main sections:

### Pool Activity Table

Displays stats per provider in the pool:

| Column | Description |
|--------|-------------|
| Provider | ChatGPT OAuth provider name |
| Requests | Total requests processed |
| Success Rate | Percentage of successful requests |
| Health Score | Current health score (0–100) |
| Fallback Count | Number of times the pool switched to this provider as fallback |
| Timeline | Activity chart over time |

### Routing Configuration

Settings for request distribution strategy.

## Configuration Guide

### Add a Provider to the Pool

1. Go to `/agents/:id` -> click **Manage Codex Pool** -> `/agents/:id/codex-pool`.
2. Click **Add Provider**.
3. Select a ChatGPT OAuth provider from the registered list.
4. Click **Save Routing Config**.

### Select Routing Strategy

| Strategy | Description |
|----------|-------------|
| `round-robin` | Distribute evenly to all providers in rotation |
| `primary-first` | Prefer the primary provider; only use secondary providers when primary fails |

After selecting a strategy, click **Save Routing Config** to apply.

### Remove a Provider from the Pool

1. Find the provider in the activity table.
2. Click **Remove** next to that provider.
3. The pool updates automatically; new requests are no longer sent to the removed provider.

### Refresh Data

Click **Refresh** to update the activity table and quota data to the current state.

### View Provider Link Details (Admin Only)

Admins can view detailed OAuth link information for each provider in the pool.

## Example — Configure Pool with 2 Providers

```
/agents/my-agent/codex-pool
  -> Add provider: chatgpt-oauth-account-1
  -> Add provider: chatgpt-oauth-account-2
  -> Strategy: round-robin
  -> Save Routing Config

Result:
  Request 1 -> account-1
  Request 2 -> account-2
  Request 3 -> account-1
  ...
  If account-1 errors -> automatically switch all to account-2
```

---

## Notes

- Codex Pool only applies to agents using a ChatGPT OAuth provider — it does not affect other providers (Anthropic, OpenAI API key, etc.).
- Providers must be registered in `/providers` before adding to the pool.
- Health score is calculated based on success rate, latency, and recent fallback count.
- When all providers in the pool fail, the agent returns an error to the user instead of hanging indefinitely.
- This feature is suitable for environments using multiple ChatGPT accounts to avoid free-tier rate limits.
