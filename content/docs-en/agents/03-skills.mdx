# Skills

## Overview

Skills are knowledge modules or instructions embedded in the system prompt that help the agent know how to use tools or handle specific domains. Unlike tools (which execute actions), skills are knowledge — the agent reads skills to understand how to work.

---

## What Are Skills

Skills are ZIP files containing:
- Tool usage instructions (e.g. how to use `pdf`, `xlsx`, `docx`)
- Task-specific processing workflows
- Internal reference documentation

**Example available skills:**

| Skill | Function |
|-------|----------|
| `pdf` | Read, create, merge, split PDF files |
| `xlsx` | Read, create, edit spreadsheets |
| `docx` | Read, create, edit Word files |
| `pptx` | Read, create, edit presentations |
| `skill-creator` | Create new skills |

**How the agent searches for skills:**

| Condition | Behavior |
|-----------|----------|
| &lt;= 20 skills and total tokens &lt;= 3,500 | Skills list is embedded directly in the system prompt (inline mode) |
| More than above threshold | Agent uses the `skill_search` tool to search by keyword (BM25 + vector search) |

---

## Visibility Scope

| Level | Access |
|-------|--------|
| `public` | All agents and users |
| `private` | Owner only |
| `internal` | Must be explicitly granted access |

---

## UI — Skills Page

Route: `/skills`
Sidebar Group: Capabilities
Access: Logged in

Displays a table with two tabs:
- **Core**: System (built-in) skills
- **Custom**: User-uploaded skills

Columns: name, description, author, status, visibility, actions.

A **Missing dependencies** table appears at the top if any skill has unmet requirements.

**Actions:**
- **Upload skill** — drag and drop a `.zip` file into the upload zone
- **Edit metadata** — name, description, visibility, tags
- **Delete skill** — with confirmation
- **Enable/Disable** — toggle per skill
- **Toggle visibility** — click the badge to cycle `public` -> `internal` -> `private`
- **Re-scan dependencies** — scan all skills
- **Install single dependency** — install individual packages
- **Organization override** — enable/disable a skill for the current organization (Toggle / Reset)

---

## Guide — Upload a New Skill

1. Go to `/skills`, click **Upload Skill**.
2. Drag and drop a `.zip` file into the upload zone (or click to select a file).
3. The system validates each file: **validating** -> **valid / invalid** -> **uploading** -> **success / error**.
4. Click **Upload [N]** to begin uploading validated files.
5. After completion, click **Done**.
6. Click **X** on a file to remove it from the queue before uploading.

## UI — Skill Detail

Route: `/skills/:id`
Sidebar Group: Capabilities
Access: Logged in

Opens as a dialog from the `/skills` page.

**Two tabs:**

| Tab | Content |
|-----|---------|
| Content | Skill README in markdown |
| Files | Select version, file tree, content viewer with syntax highlighting |

**Actions:**
- **View versions** — list all released versions
- **Browse files** — list files in the skill directory
- **Read file content** — display in viewer with syntax highlighting
- **Pin version to agent** — assign the skill to an agent at a specific version
- **Copy** — copy file content

## Tools — What Tools the Agent Can Use

Tools are executable functions (distinct from skills which are knowledge). The agent selects the appropriate tool and calls it during processing.

| Tool Group | Examples |
|------------|---------|
| Filesystem | `read_file`, `write_file`, `list_files` |
| Web | `web_search`, `browser_act`, `browser_screenshot` |
| Code execution | `exec` (run Python, Node.js in Docker sandbox) |
| Memory | `memory_search`, `memory_write` |
| TTS | `tts_convert` (text to speech) |
| Subagent | Call another agent to handle a sub-task |
| MCP tools | Tools from external MCP servers |

Each request can have its own list of permitted tools (e.g. a Telegram forum topic can restrict tools).

## Example — Add PDF Skill to an Agent

```
/skills -> Upload Skill -> drag pdf.zip
  -> Validation: valid
  -> Upload -> Success
/skills -> click "pdf" -> Detail -> Pin Version
  -> Select agent: "Assistant", version: latest
  -> Confirm
```

---

## Notes

- Skills are only knowledge — the agent still needs corresponding tools to actually execute tasks (e.g. the `pdf` skill needs the `exec` or `read_file` tool).
- `private` skills are only visible to the owner — suitable for personal internal knowledge.
- Deleting a skill used by an agent does not automatically disable the agent — the agent simply won't find the skill when needed.
- Skill version pinned to an agent: if no specific version is pinned, the agent uses the latest version.
