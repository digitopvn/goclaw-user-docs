# Session Management

## Overview

The Sessions page lets you view, search, and manage the complete conversation history in the system. The session detail page shows the full message history, metadata, and editing actions.

---

## UI — Sessions List

Route: `/sessions`
Sidebar Group: Conversations
Access: Logged in

Displays a paginated table of all sessions with columns:

| Column | Content |
|--------|---------|
| Session / User | Session key and display name |
| Agent | Agent handling this session |
| Context Usage | Progress bar: estimated tokens vs. window size + compression count |
| Messages | Total messages in the session |
| Updated | Timestamp of the last message |

**Actions:**
- **Search** — by key, label, display name, username, or chat title
- **View detail** — click a row to navigate to `/sessions/:key`

---

## UI — Session Detail

Route: `/sessions/:key`
Sidebar Group: Conversations
Access: Logged in

Displays the full message history as chat bubbles (user / assistant / system).

**Session metadata** shown at the top:

| Field | Description |
|-------|-------------|
| Agent | Agent handling the session |
| Channel | Messaging channel (web, telegram, discord, ...) |
| User | User ID |
| Peer Type | Peer type of the session |
| Tokens In/Out | Total tokens consumed |

**Summary block** (expandable): Conversation summary if the agent has generated one.

---

## Guide — Session Actions

### Edit Title

1. On the session detail page, click the title to edit it inline.
2. Press **Enter** or the checkmark (✓) icon to save.
3. Press **Escape** or the ✕ icon to cancel.

### Reset Session

Clears conversation history but keeps the session (does not remove it from the list).

1. Click the **Reset** button.
2. A confirmation dialog appears — click **Confirm Reset**.
3. Message history is cleared; the session remains.

### Delete Session

Permanently deletes the session and all its history.

1. Click the **Delete** button.
2. A confirmation dialog appears — click **Confirm Delete** (danger color).
3. After deletion, automatically redirects to the sessions list `/sessions`.

Warning: Deleting a session cannot be undone.

## Example — Search Sessions by User

```
/sessions
  -> Search box: "user123"
  -> System filters sessions belonging to user123
  -> Click a session to view full history
```

---

## Notes

- The "context usage" bar indicates when a session is approaching the context window limit — when full, the agent automatically compresses older history.
- The compression count shown in the bar: the more compressions, the less the agent remembers of older history.
- The Sessions page shows all sessions within the tenant (admins see all; regular users only see their own sessions depending on RBAC configuration).
- To resume chatting in an old session, click the session in the sidebar of the Chat page.
