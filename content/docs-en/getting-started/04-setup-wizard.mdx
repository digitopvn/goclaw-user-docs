# Setup Wizard and Dashboard Overview

## Overview

On first access to the Web Dashboard after installation, the system displays a 4-step **Setup Wizard** to configure the system from scratch. After completion, it transitions to the **Overview** page — the central monitoring hub for gateway activity.

---

## Guide — Setup Wizard

Route: `/setup`
Access: Logged in

### Step 1 — Configure Provider

Add the first LLM provider.

| Field | Description |
|-------|-------------|
| Provider Type | Select from the list (Anthropic, OpenAI, OpenRouter, ...) |
| Name | Display name for this provider |
| API Key | Authentication key for the provider |
| API Base | Base URL (optional, for self-hosted providers) |

Click **Create** to save and advance to Step 2.

### Step 2 — Select Model

Choose the default model for the provider just added.

- Select a model from the combobox.
- Click **Verify** — the system sends a test request (30-second countdown).
- After successful verification, the **Continue** button appears.

### Step 3 — Create Agent

Create the first agent.

| Field | Description |
|-------|-------------|
| Emoji | Avatar icon (optional) |
| Name | Display name for the agent |
| Agent Key | Unique slug (auto-generated from name) |
| Personality | Description of the agent's role and communication style |
| Type | **Predefined** (shared context) or **Open** (per-user context) |
| Self-evolve | Allow the agent to self-update SOUL.md |

Click **Create** — displays the **Summoning Modal** with an animated orb and real-time file progress.
- Success: **Continue** button → advances to Step 4.
- Failure: **Retry** or **Close** buttons.

### Step 4 — Connect Channel (Optional)

Connect a messaging channel (Telegram, Discord, Slack, ...).

| Field | Description |
|-------|-------------|
| Channel Type | Select type (Telegram, Discord, Slack, Feishu, Zalo, WhatsApp) |
| Name | Display name for this channel |
| Credentials | Varies by type (Bot Token, App ID, ...) |

Click **Create** to connect — displays the **Setup Complete Modal** with a **Go to Dashboard** button → `/overview`.

Click **Skip** to complete the wizard without connecting a channel (can be added later in Settings).

Other options in the wizard:
- **Change language** — vi / en / zh
- **Switch organization** — select a different organization

## UI — Dashboard Overview

Route: `/overview`
Sidebar Group: Core
Access: Logged in

After the setup wizard, this is the system home page. It has two main tabs.

### Overview Tab

Displays 5 stat cards:

| Card | Content |
|------|---------|
| Today's Requests | Total requests for the day |
| Tokens | Total tokens used |
| Cost | Estimated LLM cost |
| Agents | Number of active agents |
| Channels | Number of connected channels |

Other sections on the Overview Tab:
- **Provider alerts** — which providers are unconfigured or have errors
- **System health** — status of main components
- **Connected clients** — list of currently connected WebSocket clients
- **Cron jobs** — scheduled tasks running soon
- **Recent requests** — log of the latest requests
- **Usage quotas** — usage level relative to limits
- **Version info** — current GoClaw version

The page auto-refreshes every 30 seconds.

### Usage Tab

Detailed analysis of usage patterns over time.

**Actions:**
- **Filter** by agent, provider, channel, time range, granularity
- **Time-series chart** — request volume over time
- **Breakdown** by provider / model / channel
- **Detailed data table**
- **Export CSV** — download usage data

## Example — Complete Setup Flow

```
Login -> /login
  -> No Setup yet? -> /setup
    -> Step 1: Add Anthropic provider + API key
    -> Step 2: Select claude-sonnet-4-5-20250929, Verify OK
    -> Step 3: Create agent "Assistant", type=open
    -> Step 4: Skip channel
  -> /overview (Dashboard)
```

---

## Notes

- The entire wizard can be skipped with the **Skip** button at any step.
- After skipping, each section can be configured individually in **Settings** (Providers, Channels, Agents).
- The Usage tab on Overview is the place to track overall LLM costs — for session-level detail, use the **Sessions** page.
