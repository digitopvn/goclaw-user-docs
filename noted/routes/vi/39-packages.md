# Gói Phần Mềm

**Route:** `/packages`
**Nhóm Sidebar:** Hệ Thống
**Quyền truy cập:** Admin

## Hiển Thị
Ba phần: lưới Runtimes (khả năng sẵn có của node, python, go, v.v.) và bảng gói hệ thống, pip, npm. Mỗi bảng gói: tên và phiên bản.

## Thao Tác
- **Cài đặt gói** — ô nhập + nút cài đặt cho gói hệ thống / pip / npm
- **Gỡ cài đặt gói** — xác nhận
- **Làm mới tất cả** — tải lại thông tin runtime và gói

## Tính Năng Phụ
- Lưới runtimes: hiển thị khả năng sẵn có của node, python, go và các runtime khác
- Ba phần gói: Hệ thống, pip (Python), npm (Node)
