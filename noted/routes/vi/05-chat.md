# Chat

**Route:** `/chat/:sessionKey?`
**Nhóm Sidebar:** Core
**Quyền truy cập:** Đã đăng nhập

## Hiển Thị
Giao diện chat đầy đủ: thanh bên danh sách phiên (trái), luồng tin nhắn (giữa), bảng task nhóm (phải, tự mở).

## Thao Tác
- **Gửi tin nhắn** — văn bản + đính kèm file (kéo thả)
- **Tạo phiên mới** — bắt đầu cuộc trò chuyện mới
- **Chuyển phiên** — chọn từ thanh bên
- **Xóa phiên** — xóa phiên
- **Chuyển agent** — thay đổi agent cho cuộc trò chuyện mới
- **Dừng chạy** — dừng agent đang xử lý

## Tính Năng Phụ
- Streaming thời gian thực, chỉ báo đang suy nghĩ, hiển thị bước công cụ
- Chế độ chỉ đọc cho phiên của người dùng khác
- Giao diện thích nghi di động
