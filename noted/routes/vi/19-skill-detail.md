# Chi Tiết Skill

**Route:** `/skills/:id`
**Nhóm Sidebar:** Khả Năng
**Quyền truy cập:** Đã đăng nhập

## Hiển Thị
Hộp thoại chi tiết skill (mở từ trang Skills): metadata, lịch sử phiên bản, danh sách file, trình xem nội dung.

## Thao Tác
- **Xem phiên bản** — danh sách tất cả phiên bản đã phát hành
- **Duyệt files** — danh sách file trong thư mục skill
- **Đọc nội dung file** — hiển thị trong trình xem với tô sáng cú pháp
- **Ghim phiên bản cho agent** — cấp skill cho agent theo phiên bản cụ thể

## Tính Năng Phụ
- Mở dưới dạng hộp thoại trên trang `/skills`
- Trình xem nội dung với tô sáng cú pháp
