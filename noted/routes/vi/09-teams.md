# Nhóm Agent

**Route:** `/teams`
**Nhóm Sidebar:** Core
**Quyền truy cập:** Đã đăng nhập

## Hiển Thị
Danh sách phân trang tất cả nhóm (dạng thẻ hoặc danh sách), tìm kiếm.

## Thao Tác
- **Tạo nhóm** — mở hộp thoại tạo mới
- **Xóa nhóm** — hộp thoại xác nhận
- **Xem chi tiết nhóm** — nhấp để điều hướng

## Hộp Thoại

### Tạo Nhóm
**Trường:** Tên (bắt buộc), Mô tả, Agent Trưởng (combobox, bắt buộc), Thành viên (combobox + danh sách badge, chỉ agent định sẵn)
**Thao tác:** **Tạo** (yêu cầu tên + trưởng + ít nhất 1 thành viên) | **Hủy**
