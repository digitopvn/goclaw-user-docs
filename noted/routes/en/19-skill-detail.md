# Skill Detail

**Route:** `/skills/:id`
**Access:** Auth

## What It Shows
Skill detail dialog (opens from the Skills page). Shows skill metadata, version history, file list, and file content viewer.

## Actions
- **View versions** — list of all published versions
- **Browse files** — directory listing of skill files
- **Read file content** — view raw file content in the viewer
- **Pin version for agent** — grant skill to agent at a specific version

## Sub-features
- Opened as a dialog on top of `/skills`, not a standalone page
- File content viewer with syntax highlighting
- Version list with timestamps
