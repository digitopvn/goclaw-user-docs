# Packages

**Route:** `/packages`
**Access:** Admin

## What It Shows
Three sections — Runtimes grid and package tables for system, pip, and npm packages. Each package table shows name and version.

## Actions
- **Install package** — text input + install button for system / pip / npm packages
- **Uninstall package** — confirm dialog
- **Refresh all** — reload runtime and package data

## Sub-features
- Runtimes grid: shows availability of node, python, go, and other runtimes
- Three package sections: System, pip (Python), npm (Node)
