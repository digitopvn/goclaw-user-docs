# Activity Log

**Route:** `/activity`
**Access:** Operator+

## What It Shows
Paginated audit log table. Columns: action, actor (type:id), entity type, entity ID, IP address, timestamp.

## Actions
- **Filter by action type** — e.g., agent.created / agent.updated / agent.deleted
- **Filter by entity type** — dropdown filter
- **Refresh**

## Sub-features
- View-only audit trail
- Pagination
