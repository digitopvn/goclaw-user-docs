# Events

**Route:** `/events`
**Access:** Operator+

## What It Shows
Live real-time event feed streamed over WebSocket. Events displayed in chronological order with category, timestamp, and payload.

## Actions
- **Pause / Resume** — stop/start the live feed
- **Clear all events** — wipe the current feed
- **Filter by category** — pills: all, team.task, team.message, agent, team.crud, agent_link
- **Filter by team / user / chat** — dropdown filters
- **Scroll to bottom** — floating action button

## Sub-features
- Auto-scroll to bottom as events arrive
- Category filter pills
- Real-time WebSocket subscription
