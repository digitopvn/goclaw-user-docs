# Builtin Tools

**Route:** `/builtin-tools`
**Access:** Admin

## What It Shows
All built-in tools grouped by category. Each tool shows: display name, code name, description, requires badge, deprecated badge.

**Categories:** filesystem, runtime, web, memory, media, browser, sessions, messaging, scheduling, subagents, skills, delegation, teams.

## Actions
- **Toggle enable/disable** — switch per tool
- **Configure tool settings** — dialog for tools with editable settings
- **Set tenant override** — enable/disable tool for current tenant only
- **Reset tenant override** — revert to global default
- **Search tools**
- **Refresh**

## Sub-features
- Warning shown for media tools enabled without a configured provider
- Per-tenant override capability
- Search across all tool names and descriptions
