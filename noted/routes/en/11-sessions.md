# Sessions

**Route:** `/sessions`
**Access:** Auth

## What It Shows
Paginated table of all sessions with columns: session name/user, agent, context usage bar (token estimate vs window with compaction count), message count, last updated time.

## Actions
- **Search sessions** — by key, label, display name, username, chat title
- **View session detail** — click row to navigate to detail page

## Sub-features
- Context usage bar shows token consumption vs context window
- Compaction count indicator
- Server-side pagination
