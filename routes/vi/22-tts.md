# TTS (Chuyển Văn Bản Thành Giọng Nói)

**Route:** `/tts`
**Nhóm Sidebar:** Khả Năng
**Quyền truy cập:** Chủ sở hữu (Cross-tenant)

## Hiển Thị
Trang cấu hình TTS với thẻ trạng thái, cài đặt chung và thẻ cài đặt theo provider.

## Thao Tác
- **Chọn provider chính** — không có / openai / elevenlabs / edge / minimax
- **Chế độ tự động áp dụng** — tắt / luôn luôn / tin đến / có thẻ
- **Chế độ trả lời** — cuối cùng / tất cả
- **Cấu hình độ dài văn bản tối đa** và **timeout**
- **Cài đặt theo provider** — API key, model, giọng đọc
- **Lưu** tất cả thay đổi | **Làm mới**
