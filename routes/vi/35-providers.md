# Nhà Cung Cấp LLM

**Route:** `/providers`
**Nhóm Sidebar:** Hệ Thống
**Quyền truy cập:** Admin

## Hiển Thị
Danh sách phân trang tích hợp nhà cung cấp LLM có tìm kiếm. Hiển thị sơ đồ phân cấp pool cho ChatGPT OAuth và hạn mức OAuth.

## Thao Tác
- **Tạo provider** — hộp thoại form
- **Xóa provider** — xác nhận
- **Xem chi tiết provider** — nhấp để điều hướng
- **Tìm kiếm** | **Làm mới**

## Hộp Thoại

### Tạo Provider
**Trường:** Loại (anthropic_native, openai_compat, gemini_native, claude_cli, dashscope, openrouter, groq, deepseek, ollama, acp, v.v.), Tên, API Key, API Base, Các trường OAuth (nếu loại OAuth)
**Thao tác:** **Tạo** | **Hủy**

### Xác Nhận Xóa Provider
**Thao tác:** **Xác nhận Xóa** (nguy hiểm) | **Hủy**
