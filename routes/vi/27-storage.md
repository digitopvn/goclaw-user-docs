# Lưu Trữ

**Route:** `/storage`
**Nhóm Sidebar:** Dữ Liệu
**Quyền truy cập:** Admin

## Hiển Thị
Trình duyệt file với cây thư mục có thể mở rộng (trái) và trình xem nội dung file (phải). Hiển thị tổng dung lượng ở trên cùng.

## Thao Tác
- **Duyệt cây thư mục** — tải lazy các thư mục con khi mở rộng
- **Xem nội dung file** — file văn bản hiển thị trong trình xem; ảnh hiển thị xem trước
- **Tải lên file** — hộp thoại, tải vào thư mục hiện tại
- **Tải xuống file** — tải về máy tính
- **Xóa file/thư mục** — xác nhận
- **Di chuyển file** — kéo thả giữa các thư mục
- **Làm mới**

## Hộp Thoại

### Tải Lên File
**Trường:** Vùng kéo thả file, hiển thị đường dẫn thư mục hiện tại
**Thao tác:** **Tải lên** | **Hủy**

### Xác Nhận Xóa
Hiển thị tên file/thư mục; cảnh báo thư mục ("toàn bộ nội dung sẽ bị xóa"); không thể hoàn tác
**Thao tác:** **Xóa** (nguy hiểm) | **Hủy**
