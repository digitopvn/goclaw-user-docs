# Phê Duyệt

**Route:** `/approvals`
**Nhóm Sidebar:** Hệ Thống
**Quyền truy cập:** Operator+

## Hiển Thị
Danh sách yêu cầu phê duyệt thực thi shell đang chờ: ID agent, lệnh, thời gian.

## Thao Tác
- **Cho phép Một lần** — phê duyệt lần thực thi này
- **Luôn Cho phép** — thêm lệnh vào danh sách cho phép vĩnh viễn
- **Từ chối** — từ chối lệnh
- **Làm mới**

## Hộp Thoại

### Xác Nhận Cho Phép Một Lần
Hiển thị văn bản lệnh + ID agent
**Thao tác:** **Cho phép Một lần** | **Hủy**

### Xác Nhận Luôn Cho Phép
Hiển thị văn bản lệnh + ID agent
**Thao tác:** **Luôn Cho phép** | **Hủy**

### Xác Nhận Từ Chối
Hiển thị văn bản lệnh + ID agent (kiểu nguy hiểm)
**Thao tác:** **Từ chối** (nguy hiểm) | **Hủy**
