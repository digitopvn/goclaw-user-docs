# Agents

**Route:** `/agents`
**Nhóm Sidebar:** Core
**Quyền truy cập:** Đã đăng nhập

## Hiển Thị
Danh sách phân trang tất cả agents (dạng thẻ hoặc danh sách), tìm kiếm và lọc theo người tạo.

## Thao Tác
- **Tạo agent** — mở hộp thoại tạo mới
- **Xóa agent** — xác nhận với ô nhập tên
- **Triệu hồi lại** — khởi tạo lại agent
- **Chuyển (Import/Export)** — điều hướng đến trang import-export
- **Xem chi tiết** — nhấp để điều hướng

## Hộp Thoại

### Tạo Agent
**Trường:** Emoji, Tên, Agent Key, Provider, Model (+Xác minh), Loại (Định sẵn/Mở), Tính cách, Tự tiến hóa
**Thao tác:** **Kiểm tra** | **Kiểm tra & Tạo** | **Tạo** | **Hủy**

### Modal Triệu Hồi
Hiển thị tiến trình file theo thời gian thực
**Thao tác:** **Tiếp tục** (thành công) | **Thử lại** (thất bại) | **Đóng**
