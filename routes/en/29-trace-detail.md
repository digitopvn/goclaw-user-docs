# Trace Detail

**Route:** `/traces/:id`
**Access:** Operator+

## What It Shows
Detailed trace view opened as a dialog from the Traces page. Shows span tree, timing breakdown, token usage, and message content per span.

## Actions
- **Abort trace** — stop a running trace from the detail view
- **Navigate between traces** — previous/next trace navigation

## Sub-features
- Span tree with collapsible nodes
- Timing and token breakdown per span
- Opens as a dialog on top of `/traces`
