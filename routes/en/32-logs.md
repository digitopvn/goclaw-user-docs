# Logs

**Route:** `/logs`
**Access:** Admin

## What It Shows
Real-time log viewer with a terminal-style dark theme. Each log entry shows: timestamp, level (debug/info/warn/error), source, message, and attributes.

## Actions
- **Start tailing** — begin streaming live logs with a selected level
- **Stop tailing** — pause the live stream
- **Clear logs** — wipe the current view
- **Filter by log level** — pill buttons (debug / info / warn / error)
- **Search text** — filter visible log entries by keyword

## Sub-features
- Auto-scroll to bottom as new entries arrive
- Level selector before starting tail
- Terminal-style dark theme
