# Knowledge Graph

**Route:** `/knowledge-graph`
**Access:** Operator+

## What It Shows
Knowledge graph entity viewer scoped per agent and session. Agent selector, scope selector (built from available sessions), embedding status badge.

## Actions
- **Select agent** — choose which agent's KG to view
- **Filter by scope** — filter by user/group session scope
- **View entities** — browse KG entities in the entities tab

## Sub-features
- Embedding status badge
- Entities tab with KG entity list
- Agent and scope selectors
